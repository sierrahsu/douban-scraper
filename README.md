一个基于 Playwright 的豆瓣数据抓取工具，支持搜索功能、电影评论抓取和TOP10电影数据收集。

## 🚀 功能特性

- 🔍 **关键词搜索** - 支持多个关键词搜索，抓取相关内容
- 🎬 **电影评论抓取** - 抓取特定电影的评论和评分
- 🏆 **TOP10电影** - 自动抓取豆瓣TOP10电影数据
- 📊 **数据导出** - 结构化JSON格式输出
- 🛡️ **反爬应对** - 模拟真实浏览器行为，降低被封风险
